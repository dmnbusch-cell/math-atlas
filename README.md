# Math Atlas ✦ The Five Realms

A mobile-friendly, standalone educational game for polynomial operations, geometry naming conventions, angles, area, and quadrilaterals. This is a **separate project** from Factor Quest.

## Features
- Five animated, illustrated realms and a customizable explorer
- Multiple-choice and written answers, with hints and worked explanations
- Adaptive difficulty and unlockable levels
- Interactive geometric diagrams
- Progress saved locally on each browser/device
- No account, external libraries, or server required to play

## Publish to GitHub Pages
1. For GitHub Free, set repository visibility to **Public** under **Settings → General → Danger Zone → Change repository visibility**. This exposes the source code publicly.
2. Go to **Settings → Pages**.
3. Under **Build and deployment** select **Deploy from a branch**, branch **main**, folder **/(root)**, and **Save**.
4. After the site is deployed, open **https://dmnbusch-cell.github.io/math-atlas/**.

The HTML game is at [index.html](index.html).

Note: saved progress stays on the local device/browser and won't sync across different devices.
